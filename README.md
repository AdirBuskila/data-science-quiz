# תרגול למדעי הנתונים — Data-Science Quiz Game

משחק תרגול (עברית, RTL) לקורס *מבוא למדעי הנתונים*. מציג שאלה אמריקאית עם
אפשרויות, אתם בוחרים תשובה ומקבלים משוב/ציון. אתר **סטטי לחלוטין** (HTML+CSS+JS)
— אפשר לפתוח מקומית או לפרסם ב-GitHub Pages ללא שום שלב בנייה.

## הפעלה מקומית
פשוט פותחים את `index.html` בדפדפן (דאבל-קליק). הנתונים נטענים מ-`questions.js`
כמשתנה גלובלי, ולכן זה עובד גם מ-`file://` (ללא צורך בשרת).

## פרסום ל-GitHub Pages
1. צרו ריפו והעלו את **תוכן התיקייה הזו** (לפחות `index.html`, `styles.css`, `app.js`, `questions.js`).
2. ב-GitHub: **Settings → Pages → Build and deployment → Source: "Deploy from a branch"**, בחרו ענף `main` ותיקייה `/ (root)`.
3. תוך דקה האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

כל הנתיבים בקוד יחסיים, כך שזה עובד גם בתת-נתיב של Pages. הקובץ `.nojekyll` מונע
עיבוד מיותר ע"י Jekyll. אין תלות ברשת / CDN — האתר עובד גם אופליין.

## מאפיינים
- **שני מצבים:** *תרגול חופשי* (משוב מיידי + הסבר אחרי כל שאלה) ו-*מצב מבחן* (זמן קצוב, ציון ופירוט בסוף).
- **סינון לפי נושא** (8 נושאים) + אפשרות "מחוון רשמי בלבד" ו-"רק שאלות שטעיתי בהן".
- **ערבוב סדר התשובות** בכל הצגה (Fisher–Yates) — מנטרל את העובדה שבחלק מהמבחנים התשובה הנכונה תמיד ראשונה.
- **מעקב התקדמות** (דיוק, רצף, היסטוריה לפי שאלה) נשמר ב-`localStorage`.
- תמיכה במקלדת: ספרות `1–8` לבחירת תשובה, `Enter`/`←` למעבר לשאלה הבאה.

## מקור הנתונים ואיכותם
`questions.js` נבנה אוטומטית מארכיון המבחנים של הקורס (2024–2026) ומבנק התרגול:
- **230 שאלות** סופיות (179 ממבחנים, 51 מתרגול הקורס).
- **65** עם **מחוון רשמי** (מבחן 24A-A, מבחן לדוגמה 25-S, ומבחן 26A-B) — מסומנות "מחוון רשמי".
- **165** שתשובתן **נגזרה** מחומר הקורס (אין מחוון רשמי) — מסומנות **"תשובה לא רשמית"**; מומלץ לאמת מול המקור.
- שאלות התלויות בתרשים/גרף/קוד שלא נשמר כטקסט (36) **הוצאו** אוטומטית, כך שכל שאלה ניתנת למענה מהטקסט בלבד.

פירוט מלא: ראו `tools/build_report.md`.

## בנייה מחדש של מאגר השאלות (אופציונלי)
התיקייה `tools/` מכילה את צינור העיבוד (לא נדרש להרצת האתר):
```
python tools/extract_exams.py       # PDF -> טקסט גולמי (tools/raw/*.fitz.txt)
# מבני השאלות (tools/raw/<CODE>.json) הופקו בעזרת מודל מהטקסט הגולמי
python tools/build_questions.py      # מיזוג -> questions.js / questions.json / build_report.md
python tools/validate.py             # בדיקות תקינות
node   tools/smoke.js                # בדיקת נתונים + לוגיקת ערבוב/ניקוד
node   tools/verify_ui.js            # בדיקת UI אמיתית בדפדפן (puppeteer-core)
```

## מבנה
```
index.html · styles.css · app.js · questions.js   ← האתר עצמו (זה מה שמפרסמים)
questions.json                                     ← אותם נתונים, לשימוש חוזר
tools/                                             ← צינור עיבוד הנתונים (לא נחוץ לאתר)
```

> ⚠️ המסמך הופק לצורכי לימוד אישי. התשובות ה"לא רשמיות" נגזרו אוטומטית — יש לאמת מול חומר הקורס לפני הסתמכות.
