1. מה זה JSON בכלל?

JSON (JavaScript Object Notation) הוא פורמט טקסט קל-משקל להעברה ולשמירה של נתונים מובנים בין מערכות — הוא לא שפת תכנות, לא סוג גרף ולא שיטת מיון.

  • הפורמט הנפוץ ביותר לקבלת תשובה מ-web-API. 24B-A · 25A-A · 25A-B
  • הנתונים מגיעים במבנה מוגדר מראש — בדיוק היתרון של API על פני scraping של HTML גולמי. 26A-B
  • נראה כמעט כמו dict בפייתון: זוגות מפתח-ערך בתוך סוגריים מסולסלים.

2. איך נכון לייצג נתונים ב-JSON 24A-B שאלה 20

הייצוג הנכון הוא אובייקט עם זוגות מפתח-ערך — לכל שדה יש שם:

{
  "course_name": "intro2DS",
  "year": 2024,
  "semester": "winter"
}
אפשרותתקין?למה
אובייקט עם מפתחות (למעלה)✔ נכוןזה JSON תקין עם שמות שדות משמעותיים
<course>...</course>✘זה XML, לא JSON
["intro2DS", 2024, "winter"]✘מערך תקין תחבירית, אבל איבד את שמות השדות
{"intro2DS", 2024, "winter"}✘לא JSON תקין — סוגריים מסולסלים חייבים זוגות מפתח:ערך
כלל: מפתחות וערכי טקסט תמיד במרכאות כפולות "; מספרים בלי מרכאות; סוגריים מסולסלים {} = אובייקט (מפתח-ערך), סוגריים מרובעים [] = מערך/רשימה.

3. ארבע הפקודות — טבלה אחת שפותרת הכל

כל פקודות ה-JSON הן צירוף של שתי שאלות: (א) לאיזה כיוון? ו-(ב) מחרוזת או קובץ?

מחרוזת (String) ← יש "s"קובץ (File) ← אין "s"
קריאה / פענוח
JSON ⟵ Python
(parse)		 json.loads(s)
מחרוזת JSON → dict		 json.load(f)
קובץ JSON → dict
כתיבה / סריאליזציה
Python ⟶ JSON
(serialize)		 json.dumps(obj)
dict → מחרוזת JSON		 json.dump(obj, f)
dict → קובץ JSON
הכלל היחיד שצריך לזכור:
🔤 ה-"s" בסוף = String (מחרוזת). יש s → מחרוזת. אין s → קובץ.
📥 load = לטעון פנימה (JSON → אובייקט פייתון).   📤 dump = להשליך החוצה (אובייקט פייתון → JSON).

4. איך זה מופיע במבחן

loads — ממיר מחרוזת JSON ל-dictionary 24B-B שאלה 8

"איזו פקודה תמיר json למבנה נתונים של dictionary?" ← loads
לא load (קורא מקובץ), לא dumps/dump (הכיוון ההפוך).

dumps — ממיר אובייקט פייתון למחרוזת JSON 26A-A שאלה 1

"מה תפקידה של הפקודה json.dumps()?" ← להמיר אובייקט פייתון (כמו dict) למחרוזת בפורמט JSON (serialization).

dump — כותב dictionary לקובץ/מסמך טקסט 26A-B שאלה 3

"איזו פקודת JSON אחראית על העברה של Dictionary למסמך טקסט?" ← dump
(dump כותב לקובץ; loads קורא ממחרוזת — לכן הוא מסיח שגוי כאן.)

טריק בחירה מהיר: השאלה מדברת על מחרוזת/טקסט בזיכרון? → הפקודה עם s. מדברת על קובץ? → בלי s. ממירים מ-JSON? → load*. ממירים ל-JSON? → dump*.

5. JSON, API ו-Scraping (שאלות עקיפות)

  • API מול Scraping: היתרון של API הוא שהנתונים מגיעים במבנה מוגדר מראש (לרוב JSON נקי), בעוד scraping מחלץ מתוך HTML גולמי. 25A-A · 26A-B
  • איך מרכישים נתונים מאתר? קודם בודקים אם יש API (הדלת הראשית) ומשתמשים בו; אם אין — עוברים ל-crawling/scraping. 24A-A
  • שים לב: את תגובת ה-JSON מה-API מפענחים בפייתון עם json.loads(...) (מחרוזת → dict), לא עם BeautifulSoup (זה ל-HTML).

6. שורת הזהב לשינון

"s" = String.   loads/dumps = מחרוזת, load/dump = קובץ.  |  load = JSON ← פייתון (קריאה), dump = פייתון → JSON (כתיבה).  |  JSON = פורמט טקסט של זוגות מפתח-ערך ב-{ }.

7. תרגול מהיר (כסה את התשובות)

  1. קיבלת מחרוזת JSON מ-API ורוצה dict? → json.loads(s)
  2. רוצה לשמור dict לקובץ data.json? → json.dump(obj, f)
  3. רוצה להפוך dict למחרוזת JSON (בלי קובץ)? → json.dumps(obj)
  4. קוראים אובייקט מתוך קובץ config.json פתוח? → json.load(f)
  5. מה זה JSON? → פורמט טקסט להעברת/שמירת נתונים מובנים (לא שפת תכנות)
  6. הייצוג הנכון של רשומה ב-JSON? → אובייקט עם זוגות מפתח-ערך ב-{ }
  7. {"a", "b", "c"} זה JSON תקין? → לא (חסרים מפתחות; זו לא רשימה ולא אובייקט)
  8. יתרון API על scraping? → נתונים במבנה מוגדר מראש (JSON)
